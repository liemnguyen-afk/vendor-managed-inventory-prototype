Bulk Load Inventory Balance

Follow these steps to upload inventory balance

  1. Download the CSV template, or export the current list (Based on the CSV File Field Separator in your Language and Region settings.)
    or
  2. Fill in or update the CSV file.
    • Fields marked with a "*" are mandatory.
    • Each row uploaded will create a new inventory balance.
    • Quantity is accepted only in the item's order UoM (OUOM) or consumption UoM (CUOM). Any other UoM is rejected.
    • Click Start Upload and the system will verify the file using the first 6 rows, and load the file if no errors are found.
  3. Load the updated file

    Note: If you are loading csv files with non-English characters, please consult the following help note.
